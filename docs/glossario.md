# Glossário

Regra: código em português. Nome do projeto e mensagens de commit em inglês.
Jargões técnicos sem tradução usual (tenant, token, log) ficam em inglês.

| Termo | Significado |
|---|---|
| Tenant | Imobiliária cliente da plataforma. Nunca significa inquilino. |
| Pessoa | Pessoa física ou jurídica cadastrada. Proprietários, inquilinos e fiadores são pessoas. |
| Locação | Contrato de locação e seu ciclo de vida. |
| Cobrança | Cobrança mensal do aluguel. |
| Competência | Mês de referência de uma cobrança. |
| Repasse | Valor transferido ao proprietário após o pagamento de uma cobrança. |
